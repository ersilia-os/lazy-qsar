# dev/tests/results/

Expected-output CSV fixtures for `test_chembl.py` and `test_eosbench.py`. These files are **gitignored** and must be regenerated locally.

> **Reproducibility notice:** These results depend on external datasets, model versions, and optional descriptor dependencies. Outputs may vary across environments.

## Subdirectories

| Directory | Test file | Description |
|-----------|-----------|-------------|
| `chembl/` | `test_chembl.py` | Per-pathogen prediction CSVs from ChEMBL assay datasets |
| `eosbench/` | `test_eosbench.py` | Per-fold prediction CSVs from the EOSBench benchmark suite |

## How to regenerate

Run the corresponding tests in generation mode or follow the instructions in the test files themselves for how to produce reference outputs.
